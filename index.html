Telegram-бот для приёма заказов

Кофейня «Зерно», заказ с собой. Клиент собирает заказ кнопками и выбирает, через сколько минут заберёт его. Бариста получает заказ в рабочий чат, жмёт «Готово», и клиенту приходит уведомление.

  • Python 3.12, aiogram 3, long polling
  • SQLite через aiosqlite
  • Меню в JSON, общее для бота и демо
  • pytest: тесты корзины, времени и текстов
Код на GitHub

Демо: бот работает прямо на странице, это симуляция логики настоящего бота.
